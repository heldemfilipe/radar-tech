# Como a voz deve falar certos termos. Formato:   Termo = como falar
#
# - Vale só pro ÁUDIO; o texto das notas no Telegram continua com a grafia certa.
# - Termo todo em MAIÚSCULAS (sigla) só troca quando aparece exatamente assim
#   ("AI" troca, a interjeição "ai" não). Os outros ignoram maiúsculas/minúsculas.
# - Ouviu a voz errando alguma palavra? Adicione uma linha aqui e dê push.
# - Números romanos em nomes ("Diablo V" -> "Diablo 5") já são convertidos
#   automaticamente; não precisa listar.
#
# As grafias abaixo são aproximações do jeito brasileiro de falar. Se alguma
# ficar pior que o original, é só apagar a linha.
