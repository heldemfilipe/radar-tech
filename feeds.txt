# Um feed por linha. Linhas com # são ignoradas.
#
# Formatos aceitos:
#   https://site.com/feed/                 -> RSS normal
#   https://site.com/feed/ | Nome          -> RSS com nome fixo no episódio
#   gnews: site:exemplo.com.br | Nome      -> busca no Google Notícias (últimas 24h)
#   sitemap: <url com {data}> <trecho> | Nome -> sitemap diário (usado pro TecMundo)
#
# Pra adicionar um site: procure "nome-do-site RSS" no Google e cole a URL
# aqui — mas TESTE antes (alguns sites "chutados" devolvem 404 ou feed vazio).
# Se o site bloquear o GitHub (403/429), o script busca as notícias dele
# pelo Google Notícias sozinho — não precisa trocar a URL.
